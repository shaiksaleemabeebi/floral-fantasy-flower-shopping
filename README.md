# 🌸 Floral Fantasy – Online Flower Shopping Website

Floral Fantasy is a responsive online flower shopping website developed using HTML, CSS, and JavaScript. The project provides a simple and user-friendly interface for browsing flowers, viewing product details, managing a shopping cart, and completing the order process.

## ✨ Features

- 🏠 Home page with flower products
- 🌹 Product browsing and product details
- 🛒 Add-to-cart functionality
- 👤 User registration and login pages
- 📦 Delivery details page
- 💳 Payment page
- 👤 User profile page
- ℹ️ About page
- 📱 Responsive and user-friendly interface


## Pages

- `home.html` — Home page with flower products and website navigation
- `product.html` — Product browsing and flower product details
- `add_to_cart.html` — Shopping cart page for selected products
- `delivery.html` — Delivery information and order details
- `payment.html` — Payment page for completing the order process
- `login.html` — User login page
- `register.html` — New user registration page
- `user_profile.html` — User profile page
- `about.html` — Information about the Floral Fantasy website

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
